# Creative Brief：圓桌（暫名，見 PRD K1）

> Creative Director 產出，v1（2026-10-23，已依設計審查修訂）。與 PRD 衝突時以 `docs/PRD.md` 為準。
> 用語規則（仲裁裁決）：介面、影片、製作歷程一律用「觀點」，不用「發言」；不設「主持人」；對外不使用文章編號，一律寫「作者〈短標題〉」；「表態」改為「換你判斷」。

## 1. 創意核心
- **Big Idea**：一本叫《決策智慧》的書，最好的讀法是「帶著一個決策來讀」。
- **主張（Tagline 候選）**
  1. 「帶著問題來，帶著判斷走。」（推薦，直接說明怎麼用）
  2. 「22 篇觀點，一張圓桌，你的判斷。」
  3. 「AI 整理觀點，判斷留給你。」（呼應衡斷力）
- **語氣**：像一位資深策略夥伴在會議前幫你做 briefing：精準、克制、有溫度。不用「顛覆」「革命」這類 AI 行銷用語，也不用 emoji 堆疊。

## 2. 視覺方向（沿用刊物識別，不另起爐灶）
刊物封面的語言是**牛皮紙底 × 鉛筆素描的人臉 × ASCII 字元組成的 AI 臉 × 鐳射漸層標題**，也就是「人的手感」和「機器的字元」並置。網站延續這組對比：

| 元素 | 刊物來源 | 網站用法 |
|---|---|---|
| 牛皮紙底 | 封面 | 主背景（淡化，保證文字對比 ≥ 4.5:1） |
| 鉛筆素描 vs ASCII | 封面兩張臉 | 「作者觀點（人）」用手繪線條；「資料/結構化（AI）」用等寬字元，貫穿圓桌與「給 AI 讀的版本」 |
| 鐳射漸層 | 「決策智慧」標題 | 只用在主標與判斷卡，作為「你的決定」的高光 |
| 三大主題色 | color_system1.png：粉/紅、淺藍/藍綠、萊姆/深綠 | People／Model／AI 三章的辨識色。章節素材 artical_people1.png 確認 People＝萊姆綠；Model／AI 對應待由 artical_model1／ai1 確認 |
| 手繪插圖 | Adobe Stock 線稿組（放大鏡、長條圖、箱子、圓餅） | 空狀態、載入、決策卡插圖 |
| 字體 | 思源黑體／Montserrat／Pixelify Sans | 內文思源黑體（Noto Sans TC）；英文 Montserrat；頁碼與「AI 視角」標籤 Pixelify Sans |

注意：Adobe Stock 素材授權範圍待確認是否涵蓋公開網站（列入關鍵決策）。

## 3. 3 分鐘介紹影片：結構初稿
| 時間 | 段落 | 內容 |
|---|---|---|
| 0:00–0:20 | 問題 | 「你上次把一本刊物讀完是什麼時候？」四個範例都在回答書能長成什麼形狀；我們想回答讀者帶著什麼來 |
| 0:20–0:40 | 洞察 | 刊物叫《決策智慧》，全書主張「AI 整理、人判斷」，所以讀法也應該如此。「書塔告訴你哪幾頁談到信任；我們讓 4 篇文章針對你的問題提出觀點、拿出證據，然後換你判斷。」 |
| 0:40–1:50 | Demo | 一位行銷主管的真實情境：首頁 → 第 0 題圓桌 → 深讀一篇 → 換你判斷 → 看回饋 → 下一題 |
| 1:50–2:30 | 怎麼做的 | Vibe Coding 歷程三個轉折（附截圖），重點是「AI 初稿硬造對立 → 審查抓出 → 改成逐字比對閘門」：我們自己也照書中的方法做 |
| 2:30–2:50 | 部署與資安 | 靜態站、無後端、無個資；做過哪些檢查 |
| 2:50–3:00 | 收尾 | Tagline ＋ 網址 QR |

工具：螢幕錄影（OBS 或 Windows 內建）＋ 剪輯；若要自動化可用 Remotion 產片頭與字卡（待確認環境）。
