## 一句話診斷

技術上乾淨（無掉幀、無裁字），但**它是 20 項功能依序朗讀，不是評審跟著走的故事**。書的內容幾乎不在片裡，最強的論點「AI 會寫錯、我抓得到」被埋在 2:18。評審估分約 **58–62／100**，網站本身盲評約 78。

## 技術缺陷

- **結尾網址卡只出現約 0.1 秒**：最後合併時 `-shortest` 吃掉了 1.47 秒結尾定格。原本 4 個 chunk 有完整的 175.97 秒畫面，只要補長音訊、重新封裝即可。
- **色彩標記**：yuvj420p 全範圍＋BT.601，沒有標 BT.709，部分平台轉檔後會發灰或壓黑。
- **長時間靜止**：152–167 秒（約 14.5 秒）、76–85 秒、b13–b16 各約 8 秒。逐格序列只有 1–2.4 fps，看起來一跳一跳。
- **字幕**：第二行固定在句長 50% 時切換。b07 提早 2.7 秒，GEO 還沒講到字幕就換掉了。距底部 24px，超出安全區；疊加層小字 18–21px；網站截圖等於 CSS 像素 ×0.7，內文約 10–11px。
- **聲音**：沒有 BGM，LRA 只有 1.9 LU；段落停頓和逗號停頓一樣長（約 0.3 秒）。語速 4.43 字/秒，本身不算快。
- **可重現性**：chunk_0、2、3 是用舊版程式渲染的。路徑寫死；音訊快取會讓改過的旁白**不生效、也不報錯**；輸出不在 `docs/video/`；文件寫「可直接重現」與事實不符。

## 改版方向（創意總監＋評審共識）

**評審就是讀者**：全片沿著網站三層閱讀深度（① 全書 → ② 一篇 → ③ 原文）走一趟，以「AI 會一本正經地寫錯 → 程式抓得到」當第三幕轉折，最後回到開場的提問。

| 段落 | 秒數 | 規準 |
|---|---|---|
| 開場：書的核心提問＋全版粒子匯聚＋作品洞察（只需往下捲） | 0–20 | 創意與洞察 |
| ① 全書：臉譜、四條主線 | 20–37 | 內容策展 |
| ② 一篇從頭讀到尾：主張 → 粒子收斂 → 其他篇的圖 | 37–66 | 內容策展 |
| ③ 原文：點頁碼、推近螢光句、「每條對得回紙本」 | 66–80 | 內容策展 |
| 讀完之後：補給包＋分享卡，各一鏡 | 80–96 | 創意 |
| 轉折：真實 FAIL（p.117）→ PASS、AI 寫、程式查、判斷力不能外包 | 96–133 | 實作力 |
| 部署與資安：三個大數字 | 133–146 | 部署與資安 |
| 4/22 → 22/22 點亮、回答開場提問、網址＋QR | 146–166 | 創意與洞察 |

刪減：開場牛皮紙卡 15 秒、分享卡 18 秒 → 8 秒、補給包＋四種開箱 21 秒 → 8 秒、人機分工字卡、兩張資安小字卡。
不念的術語：D3、CSS 3D、Three.js、Astro、SHA-256、CSP、116KB。
