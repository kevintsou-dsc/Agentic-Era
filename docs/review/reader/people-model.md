# People Model｜讓消費者研究變成一場隨時能開口的對話

**用十餘年 CCS 調查一比一捏塑數位分身，讓消費者研究從一次性的調查，變成隨時能追問的對話。**

## 報告是死的，客戶的問題卻是活的

- 開場

25 歲的 Lisa 買 3C 先算「CP 值高嗎」，35 歲的 Cindy 先想「能不能解決我的麻煩」。這個答案不是猜出來的，而是「問了又問」出來的：同一群消費者隨時都在，隨時能追問。

傳統研究從問題定義、問卷設計到報告撰寫，少則數週、多則數月；等報告送到，市場可能已經轉了風向。研究成本也讓它只能用在「大哉問」上，沒有品牌會為每次臨時提問重跑焦點訪談。

> 一次問卷只能得到一次反饋，要繼續往下深究就要重做問卷，有點曠日廢時

過去的研究像一本印好的說明書，寫的時候很完整，但客戶要問的永遠不在那一頁上。他們真正想要的，是一個能被追問、能對話的消費者，這正是電通台灣開發 People Model 的出發點。

## 把十餘年的 CCS 調查，捏塑成 People Model

通用模型靠「35 歲、住台北、愛運動」一句話人設去推測角色，回答自然表淺。People Model 則注入電通獨家的 CCS 資料，這是持續十餘年、每年執行的大型消費者追蹤調查。

CCS 依性別、年齡及地區配額抽樣，在全台取得 5,000 份以上、15 至 74 歲的有效樣本。每位受訪者花約 60 分鐘完成數百道題，橫跨人口輪廓、生活態度、品牌關係、媒體接觸與購買行為。

每位受訪者的資料展開成約 6,900 個資料點，一比一捏塑成數位分身，再用來微調大型語言模型。產生的不是幾千個消費者故事，而是一群有統計結構的人，稱為 AI Persona。

> 你要它演誰，它就像誰。

## graphic

- 每個點為一個回答選項，共 9,221 點；r = 0.89 趨勢一致、MAE 9.4% 平均落差、RMSE 13.1%

模擬準不準，最終要用數字檢驗。團隊保留一部分未參與訓練的真實調查當測試集，就像學生讀完教材後還得通過一場獨立的期末考。結果，模擬與真人回答的相關係數達 0.89。

0.89 多準？想像兩個人替同一批電影打分數：你給高分的對方也給高分，你給低分的對方也給低分，品味愈一致就愈接近 1.0。通用模型的角色扮演沒有標準答案可對，People Model 每次模擬背後都有一份真人考卷。

同時檢驗的還有 MAE 9.4% 與 RMSE 13.1%。但相關係數不是誤差率，不能用「1 − 0.89」推論模型平均只差 11%，也不代表模型能正確預測每一個人的行為。

## 同樣是台北女性上班族，十歲之差

回到開場的 Lisa 和 Cindy。設定兩人的 AI Persona 後問同一件事：最近買新 3C 時在考量什麼？Lisa 依序看價格、續航、使用者評價，心裡想的是「可別花這筆錢還買到斷線爛音質」。

Cindy 則依序看續航、規格效能、價格，最怕出門在外沒電。Lisa 較開放，看重網紅試用與社群聲量；Cindy 認為代言人再紅也不代表安全好用，更看重品質聲譽與親友口碑。

這就是模擬出的「信任門檻」：不同的人對同一個行銷動作，會啟動完全不同的防禦機制。過去只能事後發現，現在能在行銷動作開始前先看到，例如為 Cindy 這類受眾強化實體試用與真實口碑。

## People Model 的 Multi-Agent 分工

品牌的商業問題很少只有一個面向。眼前的 AI Persona 看起來是一個消費者分身，背後卻是一個多 Agent 協作的系統：由 Super Agent 擔任專案負責人，拆解問題後，再把子任務分派給各領域專家。

AI Persona 負責模擬消費者觀點，Deep Research Agent 搜尋網路資料補充脈絡，CCS Agent 回頭檢索原始調查驗證，最後交回 Super Agent 比對、彙整成一份完整回答。

People Model 的價值可以收斂成四點：快，幾分鐘內展開探索；靈活，隨時調整受眾與問法；量質並進，用數字找現象、用對話補原因；縱深，多個 Agent 補上市場、媒體與生活型態的視角。

## Simulation Before Decision

- 先模擬，再決策

過去品牌最昂貴的代價，往往來自產品開發出來、預算燒下去才看成效修正。People Model 讓品牌在真實資金投入前，先在虛擬世界試錯、淘汰，只把最高勝率的方案推向真實市場。

## 不只回答「哪個比較好」

- 五個模擬案例

People Model 能派上用場的不只是「哪個比較好」。以下五個案例涵蓋創意概念、新品測試與分眾溝通，每一個都依「情境—方法—模擬」呈現：先提出問題，再看解法與模擬結果。

> 先讓消費者看見生活價值，再讓她相信一瓶真的有效。

- 方法

把產品的多個賣點分別設計成不同版本的訊息，丟給同一群 AI Persona 測試接受度排序。這一步用虛擬量化問卷就能快速跑出排序，不需要每個賣點都做一輪真人訪談。

- 模擬

售後與養護成本無憂以 73% 成為選購第一優先，明顯領先集塵與清潔容易的 14% 及續航更久的 11%；更安靜與個資安全皆無人列為第一優先。

- 模擬

五個案例回答的問題各不相同，卻都依「情境—方法—模擬」走完一輪：先提出問題，看 People Model 的解法與模擬結果，最後各自落到一個整體建議。

當每個對手都能用模擬取代猜測，真正拉開差距的，是誰能把「先模擬、後決策」變成組織的日常反射動作，而不是偶爾才用一次的工具。

模擬也有邊界。如果先向模型介紹一個陌生品牌，再問它「是否聽過」，測量本身就已受污染；沒有參考資料時，系統會明確提出「目前證據不足」，而不是生成一組看似精確的百分比。

因此輸出分成三種層次。第一種是資料直接支持的洞察，來自真實調查或可核對的資料，證據基礎明確，但仍要注意調查時間、樣本與適用母體。

第二種是模型估計：問題在模型熟悉的領域、但對不上既有問卷時，系統依過去資料估計回答分布。適合形成假設，但不能被描述成實際市場調查結果。

第三種是情境模擬：涉及新品牌、新概念或尚未發生的事件時，結果只代表在這組條件下模型可能的反應，不能當成市場已經發生的事實。

> 不是每一個問題都必須產生答案，有時候指出資料缺口，本身就是最有價值的答案。

## 三種情況，一定要搭配真人研究

- 決策金額或風險高
- 例如新品上市、品牌重新定位
- 牽涉非理性情緒或文化脈絡
- 例如危機處理、敏感議題溝通
- CCS 完全沒有可參照的相近資料
- 全新品類或行為

什麼時候要做真人研究有明確原則：決策金額或風險高、牽涉非理性情緒或文化脈絡，或 CCS 完全沒有可參照的資料。符合任一項，就搭配真人研究，用模擬做篩選、用真人做把關。

它和尼爾森、益普索等研究公司是互補關係：一邊為特定題目重新採集一手真人資料，一邊即時讀懂 CCS 已累積的態度與動機，並能反覆深問「為什麼」。
