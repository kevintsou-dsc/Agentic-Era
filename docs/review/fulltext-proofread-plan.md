# 全文校稿：LLM 多代理抽查與校稿

2026-11-08。

**目標**：網站的「原文」頁（`content/fulltext/aNN.md`，由 InDesign 檔抽出）與**印刷完稿**逐字一致。完成後拿掉「校正中」標示。

## 正本與副本

| 來源 | 角色 | 說明 |
|---|---|---|
| 單篇完稿 PDF 的**頁面圖片** | 正本 | 讀者手上的紙本就是它。`scripts/review/pdf_page.py --png` 產生 |
| 單篇完稿 PDF 的文字層 | 輔助 | 字是對的，但順序、斷行、頁眉頁碼、圖表標籤會混進來 |
| `content/fulltext-pdf/aNN.md` | 輔助 | PDF 文字層的整理版，同上 |
| `content/fulltext/aNN.md` | 受檢對象 | InDesign 檔抽出，段落乾淨。風險是：完稿後才改的字沒有同步、排版時刪掉的字還留著、頁碼標錯、圖說插在句子中間 |

素材（PDF、IDML）不進 repo，執行時以參數傳入素材資料夾路徑。

## 流程

```
第 0 輪  逐字對齊（腳本，不用模型）
         scripts/review/fulltext_diff.py → content/review/fulltext-diff/aNN.json
         排除：PDF 多出、但整段出現在圖表文字裡的（fig）；整段在另一份別處找得到的（moved）
第 1 輪  校稿員 ×5（平行，依差異數分批）
         逐處判讀差異：雜訊／網站錯誤／不確定；網站錯誤要附「精確修改」與印刷版證據
         另外通讀網站全文，找比對抓不到的結構問題（圖說插在句中、標題斷開、重複段落、頁碼錯位）
第 2 輪  覆核員 ×2（平行，不看校稿員的推理，只看提案與正本）
         每一筆修改都對照頁面圖片重新判斷：接受／駁回／改寫
第 3 輪  套用（主導者）
         只套用覆核接受的修改 → 重跑第 0 輪（差異應下降）→ npm run story:check（引文逐字比對仍須 100%）
第 4 輪  隨機抽查（獨立代理人，固定亂數種子）
         從 22 篇抽 12 個印刷頁，逐字比對網站全文與頁面圖片，計算殘餘錯誤率
         門檻：每千字錯誤 < 0.5 才標記「已校稿」；超過就回第 1 輪
```

## 判讀規則（校稿員與覆核員共用）

1. **以印刷版為準，不潤稿**。原文的錯字、用詞、標點照印刷版，不替作者修正。
2. **刻意不收的東西不算錯**：
   - 頁眉與頁碼。
   - 圖表裡的標籤，這些另存在 `content/figtext/`。
   - 註腳編號：上標數字已依設計去掉，但註腳內容 `[註]` 要保留。
3. **全形與半形、空白、引號樣式不算錯**：比對前已正規化。
4. **算錯的**：
   - **漏字**：印刷版有，網站沒有。
   - **多字**：網站有，印刷版沒有。
   - **錯字**：兩邊不同，以印刷版為準。
   - **頁碼錯位**：`<!-- p.N -->` 放錯頁。
   - **結構錯誤**：
     - 圖說或側欄插在一句話中間。
     - 標題被拆開，或和內文黏在一起。
     - 同一段重複。
5. 每一筆修改都要是 `aNN.md` 裡**唯一**的一段原字串，以及它的替換字串，越短越好。

## 產出

- `content/review/fulltext-proofread.json`：每一筆提案、覆核結果、是否套用。
- `docs/review/fulltext-proofread.md`：結果報告，含各輪數字與抽查錯誤率。
- `src/lib/fulltext.ts` 的 `FULLTEXT_REVIEWED`：抽查通過的文章才列入。
  - 原文頁的說明文字改成如實描述：經印刷版逐字比對、多代理校稿與抽查。
  - 不寫「人工校正」。

## 仲裁規則（第 1 輪後補，2026-11-08）

5 批校稿員都碰到同一組抽取工具的系統性問題，統一處理如下，覆核員依此判斷：

| # | 情況 | 處理 |
|---|---|---|
| R1 | 內文殘留註腳編號（一般數字或 Unicode 上標） | 刪除。全站設計是去掉註腳編號，`[註]` 內容保留 |
| R2 | 主標上方的引題，被放成導言後的孤立段落 | 改成主標前的第一行 `## ` |
| R3 | 多行標題被拆成多個 `## ` | **維持**（全站慣例，不影響閱讀）；駁回 B-01 |
| R4 | 編號清單掉了「1.」「2.」 | 補回，格式「1. 」接內文。原文頁逐段輸出純文字，不會被轉成清單 |
| R5 | 圖說、側欄、表格插在一句話中間，或放到別頁 | 移到該句或該段之後（同一印刷頁內），頁碼標記不倒退 |
| R6 | 正文的一部分只收在 figtext（以冒號引出的引言框、小標、側欄標題、開頭引言） | 補回全文。純粹重複內文的拉引句仍只收在 figtext |
| R7 | 頁界落在句讀附近、和印刷斷點差幾個字 | 慣例，不改；只有整個詞或短語（「因此，」）被切到錯頁才改 |
| R8 | 專家看法沒有署名（〈People Model〉） | 印刷版有署名：在側欄前補「專家看法｜姓名 職稱」，由主導者依 figtext 補上 |
