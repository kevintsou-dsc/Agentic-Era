## 實作偏離（記錄）

- L1 上限：實測 900 檔 110 KB、700 檔 214 KB（引言字集依 S5 擴大到含延伸區塊與橫捲卡片，共 954 字）。700 檔距離 220 KB 沒有餘裕，上限放寬為 280 KB；兩檔合計 324 KB，仍遠小於 fontsource 分片方案。
- L9 換場（11/2 實測後修訂）：瀏覽器原生跨頁換場要等新頁載入完才播，一般點連結時舊頁先停 0.3–0.7 秒，讀者只看到卡一下就切換（上一頁／下一頁有快取才明顯）。改為「翻紙」：點下當下紙幕由下往上蓋滿（.36s）才換頁，新頁在紙幕下開場，就緒後紙幕往上收走；頂欄不動。原生換場保留但不播動畫，只用來讓交接那一格不閃白。沒有 JS 時 1.2 秒保底收幕；減少動態時不出現。
