# 審查回合 3：用戶倡導者 → 主導設計師回應與修訂（v3）

| # | 意見 | 處置 | 修訂（v3 規格） |
|---|---|---|---|
| U1 | 主按鈕沒說會發生什麼 | **接受** | 主按鈕下方加一行說明：「約 3 分鐘｜4 篇文章回答同一個問題，最後換你判斷」 |
| U2 | 找特定文章的人沒有入口 | **接受，修正 S2** | 首頁第一屏改為「一主一次」：主按鈕＋次要入口「依章節或作者找文章」。目錄頁依 Intro/People/Model/AI 分章列出，每篇顯示標題、全部作者姓名與職稱，並提供依作者姓名篩選。S2 的「單一主行動」維持不變，次要入口不與主按鈕搶視覺 |
| U3 | 策展摘要被誤認為作者原話 | **接受，最高優先** | 每張觀點卡固定分三層，視覺上明確區分：①**整理**（策展者的第三人稱摘要，不加引號，標示「整理：策展者」）；②**原文**（一律加引號、改用不同字體樣式，附「紙本 p.xx」）；③**證據**（數字或案例，附頁碼）。介面用語「發言」改為「觀點」，圓桌只當版面比喻，不用「XX 說：」這種句式 |
| U4 | 立場光譜沒有軸、易硬造對立 | **接受，降級** | 光譜不放進 P0。關係統一用「呼應／補充／不同側重」標籤，標籤寫作者姓名與短標題。只有作者確實有一條可明說的軸時，才在該題顯示光譜並寫出兩端（例如「先守效率 ←→ 先累積記憶」），每題人工判斷；預設不顯示 |
| U5 | 內部術語太多 | **接受** | 介面只保留一個比喻「圓桌」。用語對照：決策室 → 網站名改由使用者決定（見關鍵決策）；表態 → 「換你判斷」；直接回答／延伸參考 → 「回答這題的文章／延伸閱讀」；主持人 → 刪除；立場光譜 → 只在少數題出現時顯示軸標籤 |
| U6 | 表態被強迫、選邊站、摘要空洞 | **接受** | 「換你判斷」可以跳過，「下一題」與「目錄」永遠可見。題目改問**讀者自己的情境**（例如「你的品牌現在最缺哪一層：被 AI 看見／被社群談論／被記住？」），不問「你同意哪位作者」。選完之後的回饋要有內容：對應到書中的具體建議與原文頁碼，例如「這一層的做法見 #13 吳宗霖〈重建 SOV〉的四個規劃問題，紙本 p.116 起」。回饋文字由策展者預先為每個選項撰寫，同樣受引文比對規則約束 |
| U7 | 全文藏在分頁、不知要讀多久 | **接受** | 深讀頁頂部顯示「整理約 2 分鐘｜全文約 N 分鐘」。策展層末端放明確按鈕「繼續讀全文」。全文結尾提供兩個出口：「回到來的那一題」與「這篇也回答了哪幾題」 |
| U8 | 深讀後迷路、分享連結進來沒有脈絡 | **接受** | 從題目進入的深讀頁，頂部固定顯示「來自：〈題目〉」與返回鍵（以 URL 參數 `?from=q0` 實作，不需要儲存）。直接進入單篇的讀者，頁首會看到「本篇屬於 People 章｜出現在 2 道題目」並附連結 |
| U9 | 手機光譜與編號看不懂 | **接受** | 光譜已降級（U4）。若有，手機上預設收合。全站使用者可見的地方不出現「#19」這類編號，一律寫作者姓名＋短標題；編號只用在內部 |
| U10 | 進度的空狀態、失敗狀態、收尾 | **接受** | 數字為 0 時不顯示進度；localStorage 不可用時整個進度元件隱藏；讀完所有題目後顯示收尾畫面，提供「依章節讀完整本」與「全書三條主線」 |
| U11 | 標題、頁碼與紙本不一致 | **接受** | 全站以**文章內頁標題**為準（需使用者確認，見關鍵決策），頁碼寫成「紙本 p.176」 |
| U12 | 兩種讀法沒說清楚 | **接受** | 首頁副標寫出兩種讀法：「為一個問題讀，或依章節讀」 |
