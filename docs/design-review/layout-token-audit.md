# 首頁版面與 CSS 變數系統審查

2026-11-02。範圍：首頁（`src/pages/index.astro`、`Hero.astro`）與 `src/styles/global.css` 的設計 token；字級、顏色、圓角、間距另掃了全站 `src/**/*.astro|css`。

## 結論

- 首頁目前**不是 Bento Grid**，而是「捲動敘事＋等寬卡片清單」：
  - 開場與 BookDots 捲動段是單欄敘事，這兩段不適合也不應該改成 Bento。
  - 唯一適合 Bento 的是「22 篇觀點」章節區。它現在是 `auto-fill minmax(260px, 1fr)` 的等寬等高卡片，每章各自一個網格，所以列尾會留空格。
- 顏色 token 的骨架是健全的：紙／墨三階／章節色與深色配對、`--accent` 依章節切換。問題在 token 之外的地方：
  - 元件裡有 126 處寫死的色碼。
  - 字級、間距、圓角都沒有 token。

## 1. 版面：章節區（Bento 候選）

| 實測（1366px 寬，內容寬 1152px，3 欄各 345px） | 問題 |
|---|---|
| 序章 2 篇：佔 2 格，留 1 格空 | 列尾破口，像沒排完 |
| People 9 篇：剛好 3 列 | 9 張完全同權重，看不出哪篇是章節開篇 |
| Model 5 篇：第 2 列留 1 格空；前 2 張高 152、後 3 張高 128 | 列尾破口，加上同列卡片高度不齊 |
| AI 6 篇：剛好 2 列 | ― |
| 4 個章節各自獨立網格 | 章節之間沒有共同的欄線，只是 4 張清單疊在一起 |

建議（需要你同意再動）：

- 整區改成**一個** 12 欄網格，以 `grid-auto-flow: dense` 讓章節共用欄線。
- 每章第一張做「開篇大卡」（跨 2 欄 × 2 列），帶章節色底、襯線標題、主線標籤。其餘為標準卡。
- 章節名稱改為與卡片同網格的「章節標籤磚」（跨 1 列），讓序章、People、Model、AI 的分界落在網格裡，而不是網格之間。
- 每章依篇數挑選跨欄組合，讓每列都排滿：
  - 序章 2 篇：開篇大卡加 1 張寬卡。
  - Model 5 篇：開篇大卡加 4 張標準卡，剛好 2×2。
- 卡片內容高度以 `grid-template-rows: subgrid` 對齊，同列卡片的作者行、閱讀時間行會落在同一條水平線上。
- 手機版（小於 640px）退回單欄，開篇大卡只保留章節色底。

## 2. 字體階層

- 全站有 **66 種不同的 font-size 寫法**：
  - 9、10、10.5、11、11.5、12、12.5、13、14、14.5、15……px 幾乎每 0.5px 一種。
  - 另有 20 多組各自不同的 `clamp()`。
- 13px（70 處）、12px（67 處）、11px（33 處）三者混用，承擔的都是「次要說明文字」，讀者分不出層級差異。
- **9px、10px、10.5px** 出現在圖表標註，低於 CJK 可讀下限，手機上更明顯。建議最小 11px。
- 襯線與無襯線的分工在 P1 定了「標題、陳述用襯線」，但首頁的 `.h2`「22 篇觀點」、章節 `h3`、卡片標題仍是無襯線 800。這和文章頁的標題語言不一致。
- 字重：800（81 處）和 700（77 處）並用，在 Noto Sans TC 可變字重上差異很小，等於兩個名字表達同一個層級。
- 開場導言在 800px 寬時最後一行只剩「華。」兩個字（孤字）。`text-wrap: pretty` 可以解決。

建議的字級 token（以現有最常用的值收斂，不另造新尺寸）：

| token | 值 | 用途 |
|---|---|---|
| `--fs-display` | clamp(32px, 6vw, 68px) | 頁面大標（沿用 `.display`） |
| `--fs-h2` | clamp(26px, 3vw + 12px, 40px) | 區塊標題 |
| `--fs-h3` | clamp(18px, 1.6vw + 12px, 26px) | 小標、陳述句 |
| `--fs-lede` | clamp(18px, 1.4vw + 12px, 23px) | 導言 |
| `--fs-body` | clamp(17px, 1.05vw + 12px, 19px) | 內文（沿用 body） |
| `--fs-small` | 15px | 卡片內文、說明 |
| `--fs-meta` | 13px | 作者、頁碼、出處 |
| `--fs-micro` | 11px | 眉標、圖表標註（下限） |

字重收斂為 400／600／800 三階，另加襯線的 700／900。

## 3. 顏色

| 項目 | 狀態 |
|---|---|
| 紙、墨三階、線色、三個章節色與深色配對 | 已 token 化，且「品牌色只做色塊，字一律深色」的規則清楚 ✔ |
| `--accent`／`--accent-ink` 隨章節切換 | 正確，換頁翻紙也直接吃這組 ✔ |
| 元件裡寫死的色碼 | 126 處，多數是圖表配色。最常見的是紅色系 `#c2413b`（8 處）、`#d64545`、`#b0412e`、`#b23b33`：四種相近的紅色沒有共用 token |
| 已定義 token 的值又被寫死 | `#e9e1d2`（= `--paper-2`）在 D3Chart 提示框 2 處；`#f3eee4` 只在 theme-color meta（HTML 屬性無法用變數，合理） |
| `.ch-intro` 的序章色 | 直接寫 `#e3cfa9`／`#6e4f24`，沒有 `--intro`／`--intro-ink` token，和其他三章不對稱 |

建議：

- 補上 `--intro`、`--intro-ink`。
- 補上一組「警示紅」`--signal`、`--signal-ink`，把四種紅收斂到這組。
- 寫死的 `--paper`／`--paper-2` 值改回變數。
- 圖表專用色另放 `--viz-*` 一組。圖表顏色多數照原刊重畫，保留原值，只是集中管理。

## 4. 圓角、間距、陰影

- **圓角**：12 種值，從 2px 到 16px 幾乎每個數字都用過。建議 `--r-s: 6px`、`--r-m: 12px`、`--r-l: 16px`，外加 `999px`（膠囊）與 `50%`（圓形）。
- **間距**：`gap` 有 15 種值，以 2／4／6／8／10／12／14 為主。建議改成 4px 為基數的 `--sp-1` 到 `--sp-6`：4、8、12、16、24、32。
- **陰影**：分兩種語言：
  - 卡片用柔和的投影 `0 10px 30px -18px`。
  - 按鈕與強調元件用平面錯位 `6px 6px 0 var(--accent)`，這是刊物感的硬邊。
  - 兩種都合理，但沒有命名。建議設 `--shadow-soft` 與 `--shadow-print` 兩個 token，並規定各自的用途。

## 建議的執行順序

1. **低風險**，不改外觀，只改寫法：
   - 補齊顏色 token：序章、警示紅、寫死的紙色。
   - 新增字級、圓角、間距 token，先套到首頁與共用元件。
   - 開場導言加 `text-wrap: pretty`。
2. **中風險**，外觀有變：
   - 圖表標註最小字級提高到 11px。
   - 字重 700／800 收斂。
   - 首頁 `.h2` 與章節標題改用襯線（需要把這些字加進顯示字子集）。
3. **設計變更**，需要你同意：章節區改成 Bento 網格（第 1 節）。

- 只替換「數值完全相同」的寫法，所以外觀不變：
  - 全域樣式、首頁、版型、開場的字級 30 處、圓角 13 處、間距 8 處。

**第 3 步（章節區 Bento 化）已完成，2026-11-03。**

- 不採用原建議的「開篇大卡 2×2」：
  - 每章第一篇並不比其他篇重要，放大它等於替讀者做了不存在的排序。
  - 卡片內容只有標題、副標、作者與時間，放到 2×2 會大半空白。
- 改用「章節磚」：章名本身成為網格的一格，帶章節色底，內容是英文章名、襯線中文章名、篇數與閱讀時間。
  - 跨的格數由篇數決定：補滿最後一列的空格；剛好排滿時獨佔一整列，以一行橫幅呈現。
  - 跨格數在建置時算出（`--t2`／`--t3`），以後增減文章不用手調。
- 欄數改用容器查詢固定為 1／2／3 欄，換欄點和原本 260px 最小卡寬相同，卡寬完全不變：345／302／341／343px。
- 卡片改成直向 flex，閱讀時間貼底：同一列的「精華 N 分鐘」落在同一條水平線上。
- 實測前後對照：

| 寬度 | 空格（前→後） | 區塊高度（前→後） | 閱讀時間沒對齊的列（前→後） |
|---|---|---|---|
| 1366 | 2 → 0 | 1868 → 1842 | ― |
| 1024 | 2 → 0 | 1886 → 1880 | 4/8 → 0/8 |
| 768 | 2 → 0 | 2456 → 2447 | ― |
| 375 | 0 → 0 | 3763 → 3815（+52，章節磚比原本的小標高） | ― |

- 語意：章名仍是 `h3`；清單用 `display: contents` 讓卡片進入同一個網格，並加 `role="list"` 保留清單語意。

**互動質感（動態、骨架、流光邊框、毛玻璃），2026-11-03。**

本站沒有 Tailwind，需求裡的 utility 一律換成 CSS token 與規則。各項依「不和既有衝突」調整：

- **上浮／下壓**：
  - 新增 `--ease-ui: cubic-bezier(.22,1,.36,1)`、`--dur-ui: .3s`。
  - hover 上浮 2px（只在有滑鼠的裝置），按下縮到 .98。
  - 用獨立的 `translate`／`scale` 屬性：兩者可疊加，也不會覆蓋元件自己的 `transform`。
  - 只點名套用在按鈕、細節按鈕、章節卡、下一篇卡。
  - 不套用：圖表元素、捲動卡片、翻牌卡、圖上的透明覆蓋鈕。這些本來就用 transform 定位或做動畫，硬加會跑位。
  - 減少動態時不上浮、不下壓。
- **骨架**：
  - 全站唯一的非同步載入是「原文視窗」，原本只有「載入原文…」幾個字，現在顯示兩段假段落。
  - 一道斜光依序掃過；所有行共用同一個固定背景，看起來是同一道光。
  - 延遲 .15s 才出現，載入很快時不會閃一下。
  - 順手修掉一個舊問題：載入中又點了別的出處時，較早的請求晚回來會蓋掉內容。
- **流光邊框**：
  - 只放在文章頁的主行動「讀原文」。
  - 光的顏色取章節色，和頁面同一組顏色。
  - 光邊 1.5px，和原本按鈕邊框一樣粗，尺寸不變。1px 實測在淺色章節色上幾乎看不見。
  - 減少動態時停住。
- **毛玻璃**：
  - 頂欄：半透明紙色加 24px 模糊，底緣淡墨線。在頁首時透明，往下捲 64px 內漸漸浮出（CSS scroll-driven，不用 JS；不支援的瀏覽器直接顯示毛玻璃）。
  - 圖表說明框：深色毛玻璃，1px 淡白框，頂緣水平高光線。
  - 需求裡的 `rgba(255,255,255,.08)` 白框只用在深色說明框；淺色頂欄改用淡墨線，白框在紙色上看不見。
  - 不做：捲動卡片。依 p1-02 L11，卡片底色必須不透明，避免圖從後面透出來造成字疊字。
