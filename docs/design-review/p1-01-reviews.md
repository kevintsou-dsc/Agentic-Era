# P1 審查回合：三位審查者 → 主導設計師回應與修訂（v1）

流程備註：三位審查者對 v0 **平行、各自獨立**審查（避免互相錨定），再由主導設計師依「懷疑者 → 約束守護者 → 用戶倡導者」順序逐條回應。這與 skill 要求的「依序」不同；改成平行，是為了讓三份意見彼此獨立，並節省時間。

實測補充（主導設計師，在 scratchpad 試做，未進 repo）：

- 顯示文字共 670 字（含英數）。Noto Serif TC 實例化為靜態 900 後子集成 woff2，大小 **151 KB**；靜態 700 為 **153 KB**。
- 「可變字重 600–900 子集」在 fontTools 4.62.1 出錯（`KeyError: uni3004`），改用靜態實例。
- 來源檔 `C:\Windows\Fonts\NotoSerifTC-VF.ttf`：Version 2.02，SHA-256 `c8b7df78…59d8`。name 表 ID 13 為 SIL OFL 1.1，版權字串沒有 Reserved Font Name。
