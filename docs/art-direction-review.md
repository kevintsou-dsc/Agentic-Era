# 藝術總監審查：全站視覺與互動

2026-11-02。審查範圍是首頁、22 篇捲動故事（共 175 幕）、原文頁與關於頁。實看了首頁、〈信任〉、〈重建 SOV〉的桌機（約 800px 與 1440px）畫面；手機版的檢查是讀程式碼，截圖工具在手機模擬下失效，沒有截到畫面。也讀了 `global.css`、各圖表元件與互動腳本。

評分權重（PRD）：閱讀體驗與內容策展 40／實作力 30／部署與資安 15／創意與洞察 15。下列建議都以「是否讓人更想讀完、更記得住」排序，形式新鮮但不服務閱讀的不列。

---

## 一、總評

做對的事，請守住：

- **材質一致**：牛皮紙底、纖維紋理 multiply、`#hand` 手繪濾鏡、鉛筆筆跡，整站像同一本書的延伸，不像模板。
- **章節色只用在色塊與線條**，字一律深色，可讀性穩定。
- **圖表都是為這篇重畫的**（16 張專屬插畫、11 種 d3 圖），不是通用圖表庫的長相。
- **每段主文都對得回頁碼**，出處按鈕的設計低調但隨手可得。

最大的風險不在個別頁面，而在**字體**與**節奏**：字體交給讀者電腦決定；22 篇的幕序結構太相似（見三-2）。

## 三、P1：明顯提升質感

### 1. 字體層級：加一套襯線字當「書的聲音」

現在標題、陳述、引言全用無襯線 800；引號用 Georgia。建議：

- **Noto Serif TC Black** 用於：文章大標、`statement` 幕、原文引言（`quote`）、首頁「品牌離 AI 越近」。
- 無襯線保留給主文、卡片、圖表標籤。
- 一套字級 token（`--fs-display / --fs-h2 / --fs-body / --fs-caption`）取代現在散落在元件裡的 px 值。

意義：紙本是書，網站是讀書的方式。襯線大字＝作者的聲音，無襯線＝策展者的整理，讀者一眼分得出「誰在說話」，也呼應站上「原文／策展」的區分。

### 2. 節奏：22 篇的幕序太像

統計 175 幕：`prose` 36、`quote` 31、`list` 23、`hscroll` 15、`statement` 12、`bignum` 8，其餘才是專屬圖表。多數文章是「prose → list → 圖 → quote」，引言 31 次（每篇以引言結尾，又有 7 篇中段還有 1–2 則）。

- **引言分兩種處理**：結尾引言用大襯線滿版（作者署名＋章節色細線）；中段引言縮成邊欄式 pull-quote，不佔一整幕。
- **`list` 是最「通用」的一種**（23 幕）：優先把其中 3–4 幕換成第五節提的互動，或換成專屬插圖。
- **`statement` 幕改用章節色滿版底**（目前是紙色底＋大字）：作為每篇的「換氣點」，捲過時整個畫面換一次色，節奏更明顯。

### 3. 首屏空白與換段重疊（約 800px 寬時）

- 〈信任〉第二幕「信任的來源，一路在轉移」：圖表進場前有將近一整個畫面的空白紙面。建議圖表一進入視窗就顯示第 0 步的初始狀態（灰階或線稿），不要等第一段主文觸發。
- 同一幕換段時，主文卡片淡出與圖表標題短暫重疊（約半秒，文字疊文字）。窄版時卡片底色改為不透明，或讓卡片避開圖表標題區。

### 4. 動態系統：統一緩動與時長

全站有 10 種 `cubic-bezier`、從 .2s 到 .9s 的時長各自決定。建議三組 token：

| token | 用途 | 值 |
|---|---|---|
| `--ease-out` / `--dur-1` | hover、提示、變色 | `cubic-bezier(.2,.7,.2,1)`／.18s |
| `--ease-move` / `--dur-2` | 捲動觸發的位移、長出 | `cubic-bezier(.6,0,.2,1)`／.6s |
| `--ease-spring` / `--dur-3` | 彈跳強調（只給互動回饋） | `cubic-bezier(.3,1.4,.5,1)`／.5s |

規則：**hover 永遠立即回應**（今天修的同心圓延遲就是錯開動畫的 delay 洩漏到 hover）。已逐一檢查其餘 6 處 `transition-delay`，都不會擋到 hover。

### 5. 換頁：從目錄卡片「長成」文章頁

用跨頁 View Transitions（CSS `@view-transition { navigation: auto; }`，不需要改成 SPA）：首頁文章卡片的標題與章節色塊，在點進去時平滑變成文章頁的大標與章節徽章。Chrome／Edge 支援，其他瀏覽器照常換頁，不會壞。

意義：讀者知道「我從目錄的哪一格走進來」，回目錄時也回到同一格，整本書的空間感更明確。

### 6. 每篇的結尾：讓讀者知道讀到全書哪裡

結尾目前是「引言 → 帶走的問題 → 下一篇」。建議在下一篇按鈕旁放一個迷你 BookDots（首頁那張 22 點圖），已讀過的點填色（localStorage，只存在讀者瀏覽器）。這會直接提升「更想讀完」。

## 四、P2：細節打磨

- **載入動畫的離場**：現在是淡出加放大。可改為紙張由下往上「掀起」（整頁上移、底緣帶淡陰影），延續紙的材質。不做皺摺或撕紙，這類效果先前已試過不理想。
- **載入動畫依進站頁面換字**：現在每頁都會出現載入動畫，若從文章網址直接進站，副標可以改成「正在打開〈信任〉」。
- **載入期間預載**：字體（P0-1）、首屏圖表、Hero 碎片用的兩張圖，都在 2.4 秒內完成。
- **提示文字統一**：「滑過或點一下圖中的每一圈」這類提示，有的在圖下、有的在圖內。統一位置與樣式，讀者第一次互動後就淡出。
- **照片處理**：`images` 幕共 8 處，案例照片色溫各異。統一加一層牛皮紙 multiply 或雙色調，讓照片「印在紙上」。
- **鉛筆動機延伸**：主文裡的粗體關鍵句，在捲入視窗時用鉛筆線畫一道底線（一次，不循環）。和滑鼠筆跡是同一支筆，讀者會把「筆跡」與「重點」連起來。克制使用：每幕最多一處。

## 五、讀者互動盤點

### 原則

1. **動作本身就是論點**：讀者做的動作，要讓他親身體驗那一段在說的事，不是裝飾。
2. **不靠互動也讀得懂**：主文照常可讀；互動是「再體會一次」。鍵盤可操作，減少動態時給靜態對照。
3. **每篇最多一個主互動**，避免變成遊樂場。
4. **不產生原文沒有的結論或數字**：回饋文字取自原文（附頁碼），或標明「策展示意」。
5. **觸控**：垂直拖曳會和捲動打架；手機上改為水平拖曳或點選，並設 `touch-action`。

### 已有的互動（保留）

天平拖曳（〈信任〉、〈AI 普及下的演算法世代〉、〈拒絕同質化 AI Slop〉）、首頁碎片推開、紙上鉛筆筆跡、圖表 hover 說明、圖片放大、`dentsu` 彩蛋。

## 六、效能與載入

- 載入動畫（今天已改）：**每個瀏覽階段第一次進站必定顯示，至少 2.4 秒**；頁面 load 之後才淡出，最多等 6 秒；不論從首頁或文章網址進站都會出現；同一階段再進其他頁不出現。減少動態時照樣顯示，但不播放動畫。
- 這段時間可預載字體（約 1 MB 內）與首屏圖表，所以 P0-1 的字體成本被載入動畫吸收。
- 新互動都只在進入視窗時啟動（沿用 d3charts 的 IntersectionObserver 模式），不增加首屏負擔。
